# «Не разбуди Славика» (рабочее название)

Кооперативная Roblox-игра на 2 игроков (можно и больше).
Вечер, деревня, футбол на импровизированных воротах. Одни ворота стоят у сетки, вторые у дома.
За сеткой спит Славик. Перебил мяч через сетку — придётся тихо лезть за мячом.
Разбудил его — начинается хоррор: бегите в дом, закрывайте дверь и держитесь до рассвета.

## Как играется (прототип)

| Фаза | Что происходит |
|---|---|
| **Лобби** | Ждём игроков, потом 10 секунд отсчёта |
| **Футбол** (5 мин, темнеет) | Команды ДОМ и СЕТКА. ДОМ бьёт в ворота у сетки, поэтому рискует перебить. Мяч за сеткой даёт +34 к «сну Славика». Кто бегает рядом с ним, тоже его будит (крадись на C). Шкала на 100 = Славик проснулся. Если не разбудили, через 5 минут стемнеет и он встанет сам |
| **Хоррор** (4 мин до рассвета) | Ночь, туман. Славик 4 секунды поднимается, потом охотится. В доме: **E** закрыть дверь, **держать R** подпереть, **E** у шкафа спрятаться (максимум 25 сек). Он ломится в дверь и стучит в окна. Пойманный игрок попадает в стеклянную комнату наблюдателя |
| **Итоги** | Рассвет и список выживших, либо «Славик поймал всех». Потом новый раунд |

Управление: **ЛКМ / F** удар (чем дольше держишь, тем сильнее), **C / Ctrl** красться.
На телефоне есть кнопки «УДАР» и «КРАСТЬСЯ».

## Структура

```
roblox-game/
  default.project.json        -- проект Rojo
  src/shared/   -> ReplicatedStorage.Shared
    Config.luau               -- ВСЕ цифры игры (скорости, время, урон, ID звуков)
    Remotes.luau              -- связь сервер <-> клиент
  src/server/   -> ServerScriptService.Server
    GameLoop.server.luau      -- фазы: лобби -> футбол -> хоррор -> итоги
    MapBuilder.luau           -- карта-заглушка (или твоя карта Workspace.Map)
    Football.luau             -- мяч, удары, голы, аут, «мяч за сеткой»
    Slavik.luau               -- Славик: сон, пробуждение, погоня (PathfindingService)
    House.luau                -- дверь (HP, подпереть, выбить), шкафы
  src/client/   -> StarterPlayer.StarterPlayerScripts.Client
    Controls.client.luau      -- удар с зарядом, красться, кнопки для телефона
    UI.client.luau            -- счёт, таймер, шкалы, сообщения
    Ambience.client.luau      -- скримеры, тряска камеры, звуки
```

## Как запустить в Roblox Studio (через Rojo, ~10 минут)

1. Поставь **Roblox Studio** (create.roblox.com).
2. Поставь **Rojo**:
   - в Studio: вкладка *Plugins / Toolbox*, найди плагин **Rojo** (автор *Rojo*) и установи;
   - на компьютер: скачай `rojo` со страницы github.com/rojo-rbx/rojo/releases (файл для Windows: `rojo-…-windows-x86_64.zip`), распакуй.
3. Скачай этот репозиторий (ветка `claude/roblox-football-horror-game-0hojg3`) и открой терминал в папке `roblox-game`.
4. Выполни `rojo serve` (если rojo.exe лежит рядом, пиши `.\rojo.exe serve`).
5. В Studio создай пустой проект *Baseplate*, удали деталь `Baseplate`, нажми в плагине Rojo **Connect**.
6. Нажми **Play**. Карта-заглушка построится сама.
7. Тест на двоих: вкладка **Test → Clients and Servers → 2 Players → Start**.

Для теста одному в `Config.luau` уже стоит `MinPlayers = 1`. Перед релизом поставь 2.

## Своя локация

Построй карту в Studio и положи её в папку **`Workspace.Map`**. Тогда заглушка не строится.
Внутри (на любой глубине) должны быть детали с такими именами:

| Имя | Что это |
|---|---|
| `BallSpawn` | где появляется мяч |
| `GoalHouse`, `GoalFence` | невидимые зоны ворот (у дома / у сетки) |
| `FenceZone` | большая невидимая зона за сеткой (мяч туда = Славик злится) |
| `SlavikSpot` | где спит Славик |
| `SpawnHouse`, `SpawnFence` | старт команд |
| `HouseDoor`, `DoorHinge` | дверь и точка петли |
| `DoorOutside` | точка снаружи перед дверью |
| `HouseInterior` | невидимая зона «внутри дома» |
| `HouseLight` | лампочка (с PointLight), будет мигать |
| папка `Closets` | шкафы (детали) |
| папка `PatrolPoints` | точки, где бродит Славик |
| `Spectator` | пол комнаты для пойманных |

Если чего-то не хватает, в Output будет понятная ошибка с именем детали.

## Звуки

Вставь ID звуков из Creator Store в `Config.Sounds` (только звуки, которые разрешено использовать).
Пока строки пустые, игра работает без звука.
