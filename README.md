# «Не разбуди Славика» (рабочее название)

Кооперативная Roblox-игра на 2 игроков (можно и больше).
Вечер, деревня, футбол на импровизированных воротах. Одни ворота стоят у сетки, вторые у дома.
За сеткой спит Славик. Перебил мяч через сетку — придётся тихо лезть за мячом.
Разбудил его — начинается хоррор: бегите в дом, закрывайте дверь и держитесь до рассвета.

## Как играется

| Фаза | Что происходит |
|---|---|
| **Лобби** | Ждём игроков, потом 10 секунд отсчёта |
| **Футбол** (5 мин, темнеет) | Команды ДОМ и СЕТКА. Мяч за сеткой — +34 к «сну Славика». Лезть за мячом надо крадучись (C), бег рядом будит. 100 — проснулся. Не разбудили — через 5 мин встаёт сам |
| **Хоррор** | Ночь. Цель — **сбежать на дедовом тракторе**: найти ключи, канистру и аккумулятор (каждый раунд в новых местах). Аккумулятор сел — заряжать на генераторе в сарае (громко!). Потом «Завести и уехать» — кто рядом с машиной, тот спасся. Запасной вариант — дожить до рассвета (8 мин) |
| **Итоги** | Кто уехал / дожил / пойман. Новый раунд |

**Славик** видит конусом (с фонариком тебя видно вдвое дальше), слышит бег, генератор, хлопки дверей, машину.
Потерял тебя — идёт туда, где видел, и обыскивает. Ломает закрытые двери на пути.
Видел, как ты залез в шкаф, — вытащит.

Управление: **ЛКМ / F** удар (держи для силы), **C / Ctrl** красться, **Q** фонарик,
**E** взять / двери / шкаф / действие, **R** подпереть дверь, **F** у трактора — завести.
На телефоне — кнопки «УДАР», «КРАСТЬСЯ», «ФОНАРЬ».

## Структура

```
roblox-game/
  default.project.json        -- проект Rojo
  src/shared/   -> ReplicatedStorage.Shared
    Config.luau               -- ВСЕ цифры игры (скорости, время, урон, ID звуков)
    Remotes.luau              -- связь сервер <-> клиент
  src/server/   -> ServerScriptService.Server
    GameLoop.server.luau      -- фазы: лобби -> футбол -> хоррор -> итоги
    MapBuilder.luau           -- карта-заглушка (или твоя карта Workspace.Map)
    Football.luau             -- мяч, удары, голы, аут, «мяч за сеткой»
    Slavik.luau               -- Славик: сон, пробуждение, погоня (PathfindingService)
    House.luau                -- дверь (HP, подпереть, выбить), шкафы
  src/client/   -> StarterPlayer.StarterPlayerScripts.Client
    Controls.client.luau      -- удар с зарядом, красться, кнопки для телефона
    UI.client.luau            -- счёт, таймер, шкалы, сообщения
    Ambience.client.luau      -- скримеры, тряска камеры, звуки
```

## Как запустить в Roblox Studio (через Rojo, ~10 минут)

1. Поставь **Roblox Studio** (create.roblox.com).
2. Поставь **Rojo**:
   - в Studio: вкладка *Plugins / Toolbox*, найди плагин **Rojo** (автор *Rojo*) и установи;
   - на компьютер: скачай `rojo` со страницы github.com/rojo-rbx/rojo/releases (файл для Windows: `rojo-…-windows-x86_64.zip`), распакуй.
3. Скачай этот репозиторий (ветка `claude/roblox-football-horror-game-0hojg3`) и открой терминал в папке `roblox-game`.
4. Выполни `rojo serve` (если rojo.exe лежит рядом, пиши `.\rojo.exe serve`).
5. В Studio создай пустой проект *Baseplate*, удали деталь `Baseplate`, нажми в плагине Rojo **Connect**.
6. Нажми **Play**. Карта-заглушка построится сама.
7. Тест на двоих: вкладка **Test → Clients and Servers → 2 Players → Start**.

Для теста одному в `Config.luau` уже стоит `MinPlayers = 1`. Перед релизом поставь 2.

## Своя локация

Построй карту в Studio и положи её в **`Workspace.Map`** (Folder или Model) — тогда заглушка не строится.

**По имени** (одна деталь, можно невидимую, на любой глубине внутри Map):

| Имя | Что это |
|---|---|
| `BallSpawn` | где появляется мяч (центр поля) |
| `GoalHouse`, `GoalFence` | невидимые зоны ворот (у дома / у сетки) |
| `FenceZone` | большая невидимая зона за сеткой |
| `SlavikSpot` | где спит Славик (точка на земле) |
| `SpawnHouse`, `SpawnFence` | старт команд |
| `HouseInterior` | невидимая зона «внутри дома» |
| `HouseLight` | лампочка с PointLight (будет мигать) |
| `EscapeCar` | трактор (главная деталь) |
| `Generator` | генератор в сарае |
| `Spectator` | пол комнаты для пойманных (высоко над картой) |

**По тегу** (Tag Editor / вкладка Properties → Tags; можно сколько угодно):

| Тег | На что вешать |
|---|---|
| `SlavikDoor` | двери. Петля — левый край. Атрибуты: `OpenAngle` (градусы, по умолчанию -90), `MaxHP` |
| `SlavikCloset` | шкафы. Выход — со стороны передней грани (-Z) |
| `SlavikItemSpawn` | невидимые точки, где могут лежать предметы (минимум 3, лучше 10+) |
| `SlavikPatrol` | невидимые точки, где бродит Славик |

**Красивые модели вместо блоков:**
- `ServerStorage.SlavikModel` — модель Славика (Humanoid + HumanoidRootPart, лучше R15). ID анимаций — в `Config.SlavikAnimations`.
- `ServerStorage.Items.Keys / Fuel / Battery` — модели предметов (деталь или Model с PrimaryPart).

### Готовая локация «Деревня» (tools/BuildVillageMap.luau)

Карта по концепту (`docs/concept.png`, фото `docs/refs/`) собирается скриптом `tools/BuildVillageMap.luau`:
вставь его текст в Command Bar Studio (режим редактирования) и нажми Enter — старый `Workspace.Map`
удалится и построится заново (поле, сетка-рабица, лежбище Славика, дом на две семьи с верандой и кухней,
сарай с поленницей и генератором, берёзы, огород за домом с грядками, яблонями и ягодными кустами,
дыра в заднем заборе к соседям, трактор МТЗ у ворот рядом с сараем, чёрный кот у крыльца, забор, террейн,
ночной свет, все имена и теги).
Меш-модели (берёзы, трактор, кот, яблоня, бочки — бесплатные из Creator Store, скрипты удалены) лежат в
`ServerStorage._MapAssetsStaging`; без них скрипт ставит простые заглушки.
Локация стоит в стороне от остальной сцены: центр поля в (3000, 0, 0).
`Lighting → Technology = Future` нужно включить вручную (из скриптов это свойство не меняется).

## Звуки

Вставь ID звуков из Creator Store в `Config.Sounds` (только звуки, которые разрешено использовать).
Пока строки пустые, игра работает без звука.
