## 2. Идея игры

**Жанр:** кооперативный «футбол → хоррор» на 2 игрока (можно до 4), сессия ~10 минут.

**Сеттинг:** русская деревня, летний вечер. Двор, импровизированные ворота (ящики), одни ворота
у сетки-рабицы, вторые у дома. За сеткой на матрасе спит Славик.

**Цикл раунда:**
1. **Футбол (вечер, темнеет).** Две команды: ДОМ и СЕТКА. Перебил мяч через сетку — кто-то должен тихо
   пролезть за ним. Шум рядом со Славиком и мячи за сетку заполняют шкалу его сна.
2. **Пробуждение.** Шкала 100 (или стемнело): ночь, туман, красные глаза, «ИМЯ РАЗБУДИЛ СЛАВИКА!».
3. **Хоррор — побег на дедовой Ниве.** Найти ключи, канистру, аккумулятор (случайные места).
   Аккумулятор зарядить на генераторе в сарае (громко — Славик идёт на звук). Завести Ниву и уехать.
   Славик видит (конус, фонарик выдаёт), слышит (бег, генератор, двери), ищет, ломает двери,
   вытаскивает из шкафа, если видел. Запасной вариант — дожить до рассвета.
4. **Итоги:** кто уехал / дожил / пойман, счёт матча, новый раунд.

**Локация (по концепту):** длинный старый деревянный дом на две семьи (левая половина в зарослях,
голубая дверь; правая — коричневая дверь, фонарь над ней, разбитое окно), чердак, справа сарай
с поленницей и огромная берёза, бочки, забор, туман, луна. Реализм: ночь, тёплый свет лампочек,
холодный лунный свет.

**Славик (внешность по концепту):** средний рост, лысый, борода, тёмная расстёгнутая рубашка,
левая щека в крови, левая нога — протез. Взгляд: удивление и агрессия одновременно.
**Контент (правила Roblox):** Славик — злодей-страшилка, не насмешка над бездомными или людьми
с инвалидностью (протез — просто деталь образа). Кровь только как на концепте (пятно на щеке),
без расчленёнки и жестокости. Перед публикацией честно заполнить анкету Maturity & Compliance.

**Почему вернутся / виральность:** «кто разбудил Славика» в чате и роликах, смешные провалы,
разные события (Славик то храпит, то бормочет), скины мяча, шапок, фонариков.

## 3. Технический стек

- Roblox Studio + Luau (`--!strict` где возможно).
- **Rojo**: код лежит в `src/`, синхронизируется в Studio (`rojo serve`).
- **Roblox Studio MCP** (когда Claude Code запущен локально на компьютере со Studio):
  Studio → Assistant → «…» → Manage MCP Servers → «Enable Studio as MCP server» → Quick connect → Claude Code.
- Git для истории.

## 4. Структура и синхронизация со Studio

Код — в `src/` (истина — файлы в git). Карта и модели живут только в Studio (сохранять через
File → Publish to Roblox / Save to Roblox).

Перенос кода в Studio через MCP (если Rojo не подключён):
- `src/shared/*.luau` → `ReplicatedStorage.Shared` (ModuleScript)
- `src/server/*.server.luau` → `ServerScriptService.Server` (Script), остальные `src/server/*.luau` → ModuleScript там же
- `src/client/*.client.luau` → `StarterPlayer.StarterPlayerScripts.Client` (LocalScript)
- Имя скрипта = имя файла без расширений. Перед переносом — `git pull`. Удалять в Studio скрипты,
  которых больше нет в `src/`. Правишь код в Studio — правь и файл в `src/`, потом commit + push.

Серверные модули: GameLoop, MapBuilder, Football, Slavik, House (шкафы), Doors, Objectives (побег),
Noise (шум), Flashlight. Клиент: Controls, UI, Ambience. Карта: имена + теги — см. README.

## 4.1 Реализм (визуал)

- Lighting.Technology = Future, Atmosphere, ColorCorrection, Bloom, лёгкий DepthOfField.
- Террейн (трава, грязь), а не блоки. Деревья, дом, сарай, забор — меш-модели из Creator Store
  (только с разрешением на использование) или импорт FBX. Материалы — PBR / SurfaceAppearance.
- Свет: мало, но тёплый и с тенями; ночью лунный свет холодный.
- Следить за производительностью на телефоне: StreamingEnabled, не больше ~200 источников света.

## 5. Правила кода

- Все цифры только в `src/shared/Config.luau`.
- Сервер решает всё важное (голы, гнев Славика, поимка, дверь). Клиенту не доверяем.
- Каждый RemoteEvent проверять на сервере: тип данных, дистанция, кулдаун.
- Славик: PathfindingService, путь пересчитывать 2–4 раза в секунду.
- Детали карты Anchored, не больше ~200 источников света.
- Комментарии в коде на русском.
- Своя карта = папка `Workspace.Map` с деталями по именам из README.
